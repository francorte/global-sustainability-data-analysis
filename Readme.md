# Global Sustainability Data Analysis

This repository contains a collection of data analysis projects focused on global sustainability, energy systems, climate indicators, and sustainable development goals.

The analyses are designed to be:
- Reproducible
- Well-documented
- Oriented toward decision-making and policy insights

Each project is developed using Python and presented as a structured Jupyter notebook with clear explanations and visualizations.

---

## Repository Structure

- `notebooks/`  
  Contains all analysis notebooks.

- `data/`  
  Placeholder for data documentation (raw datasets are not stored in this repository).

---

## Topics Covered

- Sustainable energy and energy access
- Energy transition and renewables
- Climate change and emissions
- Economic development and energy use
- Sustainable Development Goals (SDGs)
